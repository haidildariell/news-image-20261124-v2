# The Day in World News — Tuesday 24 November 2026

A one-page news front page as a single PNG, generated by a pure
Python 3 standard-library program (its own TrueType rasteriser and
PNG encoder — no PIL, no network, fully deterministic).

The page carries 34 stories from Tuesday 24 November 2026 across 6
continents: the COP31 collapse in Antalya, Asia's market rally on
Jensen Huang's return to Nvidia, Ukraine's drone strike at Benghazi,
the Hanoi explosion, plus eight mid-page stories and 22 one-liners,
a where-it-happened map and a date-check box.
